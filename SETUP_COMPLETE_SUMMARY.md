## TROUBLESHOOTING:

### Q: Browser not showing changes?
**A:** Make sure you:
1. Saved the file in Notepad (`Ctrl+S`)
2. Refreshed the browser (`F5`)
3. Did hard refresh (`Ctrl+F5`) to clear cache

### Q: Which file should I edit?
**A:**
- Homepage = `index.html`
- Contact page = `contact.html`
- About page = `about.html`
- etc.

### Q: Made a mistake, how to undo?
**A:**
- In Notepad: `Ctrl+Z` to undo
- If file saved: Can manually revert changes
- Or ask Claude Code to restore original

### Q: Want better editor than Notepad?
**A:**
- Download VS Code: https://code.visualstudio.com/download
- Or Notepad++: https://notepad-plus-plus.org/
- Then run: `OPEN_VSCODE_PROJECT.ps1`

### Q: Server stopped working?
**A:** Check if running:
```
netstat -ano | findstr ":8000"
```
If not running, start it:
```
cd C:\Users\Owner\Desktop\VelocityRealEstate
npx http-server -p 8000
```
