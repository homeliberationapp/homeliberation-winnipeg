STEP 1: ARRANGE YOUR WINDOWS
----------------------------
You should now see:

STEP 2: OPEN A FILE TO EDIT
----------------------------
In the Explorer window:
- Find "index.html" or any HTML file
- Right-click on it
- Select "Edit" or "Open with" → Choose your editor:
  * VS Code (if installed)
  * Notepad++ (if installed)
  * Notepad (always available)

STEP 3: SPLIT SCREEN
----------------------------
Windows Snap feature:
- Click browser window
- Press: Win + Left Arrow (snaps to left half)
- Click editor window
- Press: Win + Right Arrow (snaps to right half)

Now you have:
- LEFT SIDE: Website preview (browser)
- RIGHT SIDE: Code editor

STEP 4: EDIT AND VIEW
----------------------------
1. Edit the HTML/CSS/JS in your editor (right)
2. Save the file (Ctrl+S)
3. Refresh browser (F5 or Ctrl+R) (left)
4. See your changes!
5. Repeat!
